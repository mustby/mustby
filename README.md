## 🏈 Featured Project — Waiver Wizard

**[fantasywaiverwizard.com](https://fantasywaiverwizard.com)**

> Real-time fantasy football intelligence. Live, with paying subscribers.

The waiver wire makes or breaks fantasy seasons. Waiver Wizard watches ESPN leagues 24/7 and fires alerts the moment player projections shift or injury statuses update, so you act before your league mates even know something changed.

- AI-powered daily digest + weekly waiver rankings (Claude + Perplexity)
- Real-time player monitoring every 5 minutes during the NFL season
- Automated Twitter/X content engine for news, debates, and draft coverage
- Stripe-gated free/paid tiers with live, paying subscribers

**Stack:** Next.js 16 · TypeScript · Supabase · Stripe · Resend · Vercel Cron · Claude API · Perplexity API

## Other Builds

### MOR Inbox Agent — Monitor · Organize · Respond
One agent managing 60+ Gmail inboxes across 40+ newsletter brands simultaneously. Incoming subscriber emails are classified by Claude AI, replied to within minutes, and routed to the right action: unsubscribe suppression in Beehiiv/Earnware, logging to Google Sheets, Slack escalations for issues and complaints. Zero manual inbox monitoring.

**Stack:** Node.js · TypeScript · Express · Claude API · Gmail API · PostgreSQL · React

### Reporting Agent
Newsletter health monitoring for a multi-brand portfolio. Runs every morning, pulls metrics from Beehiiv and GreenArrow, compares against 30-day rolling averages, and fires Slack alerts + HTML email reports when open rates drop, unsubscribes spike, or sends go missing. Catches problems before anyone has to ask.

**Stack:** Python · Docker · Beehiiv API · SQLite · Slack Webhooks
